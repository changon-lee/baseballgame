# 삼성 라이온즈 야구

폰 브라우저에서 바로 하는 개인용 야구게임이에요. 삼성 라이온즈로 KBO 구단을 상대해요.

- **투구 (초 공격)**: 스트라이크존 위를 드래그해서 포수 미트 위치를 정하고, 구종을 고른 뒤, 게이지가 초록 구간 한가운데일 때 화면을 터치해요. 지칠수록 초록 구간이 좁아져요.
- **타격 (말 공격)**: 공이 오는 타이밍에 맞춰 화면을 터치해요. 공이 맞으면 안드로이드는 진동이 와요.
- **감독**: 메뉴의 "타순 편집"에서 타순과 선발투수를 정하고, 경기 중 "투수 교체"로 불펜을 올려요.

## 선수 명단 고치기

`js/data/rosters.js`를 열어서 고치면 돼요. 파일 맨 위에 능력치 뜻이 적혀 있어요. 고친 뒤 GitHub에 다시 올리면 1~2분 뒤 게임에 반영돼요.

## PC에서 미리 보기

```
python serve.py 8000
```

브라우저에서 `http://localhost:8000`을 열어요. (윈도우 기본 `python -m http.server`는 JS를 잘못된 형식으로 보내서 게임이 안 열려요.)

## 테스트

Node.js 20 이상이 필요해요.

```
npm test
```

## 개발용 주소

- `#game` 또는 `#game-kia`: 메뉴 없이 1이닝 경기 바로 시작
- `#lineup`: 타순 화면 바로 열기
- `art-preview.html#pitch` / `#bat` / `#swing` / `#field` / `#closeup`: 그림 확인용 정지 화면
