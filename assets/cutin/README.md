# 컷인 영상·그림 넣는 법

경기 중 홈런·삼진·승리 장면에는 코드로 만든 연출(번쩍임, 금색 배너, 색종이 등)이 기본으로 나와요.
여기에 영상이나 그림을 넣으면 그 연출 **뒤에 깔려요**(화면을 꽉 채워 재생, 소리 없이 반복).

1. 파일을 이 폴더(`assets/cutin/`)에 넣어요. 영상은 `.webm` 또는 `.mp4`, 그림은 `.webp` `.png` `.gif`.
2. `manifest.json`에 종류별로 파일 이름을 적어요(폴더 이름 없이 파일 이름만).

```json
{
  "homerun": "homerun.webm",
  "homerun_bad": "sad.webp",
  "strikeout": "strikeout.mp4",
  "win": "win.webm"
}
```

| 종류 | 언제 나오나 | 길이 |
|---|---|---|
| `homerun` | 내가 홈런을 쳤을 때 | 2.4초 |
| `homerun_bad` | 내가 던져서 홈런을 맞았을 때 | 1.7초 |
| `strikeout` | 내가 던져서 삼진을 잡았을 때 | 1.6초 |
| `win` | 경기에서 이겼을 때 | 4.8초 |

팁: 영상은 세로(폰 화면) 비율이 좋아요. 2~4초, 용량은 1MB 안쪽이면 빠르게 떠요.
없는 종류는 코드 연출만 나오고, 파일을 못 찾으면 조용히 건너뛰어요.
