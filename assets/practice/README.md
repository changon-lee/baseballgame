# 연습장 배경 그림 넣는 법

연습장에는 코드로 만든 배경(타격 = 배팅 케이지 그물, 투구 = 불펜 철망)이 기본으로 나와요.
직접 만든 그림을 넣으면 그 그림이 **화면 전체 배경**으로 대신 쓰여요(꽉 채우고 넘치는 부분은 잘려요).

1. 그림 파일(`.webp` `.png` `.jpg`)을 이 폴더(`assets/practice/`)에 넣어요.
2. `manifest.json`에 파일 이름을 적어요(폴더 이름 없이 파일 이름만).

```json
{
  "bat": "batting_cage.webp",
  "pitch": "bullpen.webp"
}
```

- `bat` = 타격 연습, `pitch` = 투구 연습. 하나만 적어도 돼요.
- 투수·타자·포수 그림이 그 위에 그려지니, 홈플레이트 쪽(화면 아래 가운데)이 비어 있거나 잔디·흙이 있는 구도가 좋아요.
- 폰 세로 화면 비율(예: 1080×1920)이 가장 자연스러워요.

## 위치 맞추기 (선택)

그림 속 마운드·홈플레이트가 게임이 선수를 그리는 자리와 어긋나면, 파일 이름 대신 이렇게 적어요.

```json
{
  "bat": { "file": "batting_cage.webp", "at": [0.5, 0.472], "zoom": 1.25 },
  "pitch": { "file": "bullpen.webp", "at": [0.503, 0.58], "zoom": 1.5 }
}
```

- `at`: 그림 속 기준점(가로, 세로, 0~1 비율). 타격 연습은 **마운드 투수판**(투수가 서는 곳), 투구 연습은 **홈플레이트 가운데**.
- `zoom`: 화면을 꽉 채우는 크기 대비 확대 배율(1~4). 기준점을 맞추다 화면 끝에 빈틈이 생기면 그림을 밀어서 메워요.
